# ABTalks — AI Usage Log

## Project

ABTalks — 60-Day Coding Challenge Platform

## Problem Statement

Problem Statement 1 — Redesign ABTalks

## Purpose

ABTalks is a 60-day proof-of-work coding challenge platform for Indian college students.

Students build a project every day and submit proof through GitHub and LinkedIn. The redesign focuses on mobile-first usability, motivation, consistency, and recruiter visibility.

# Design Decisions

## Mobile First

The primary target viewport is 390px because the platform is primarily used by college students on smartphones.

## Late Night Grace Period

A thoughtful UX feature was introduced for the target audience.

Students can submit daily proof until 4:00 AM IST.

This addresses the real usage pattern of students coding after college hours and prevents unnecessary streak loss.

## Proof of Work

The product emphasizes actual engineering output rather than certificates.

Daily proof includes:

- GitHub commit/repository
- LinkedIn post

## Gamification

The experience uses:

- Streaks
- XP
- Achievements
- Progress
- Leaderboards

to encourage consistent participation.
